## 三步开始用

### 01 · 装好 EasyAI
选择上方对应你电脑的安装包，安装后打开。

### 02 · 选一个想用的 AI
在 AI 工作台找到 Codex、Claude 等工具，点击安装，跟着进度完成。

### 03 · 选模型，直接开工
打开配置，选择模型并应用。然后打开桌面工具，或新建一个命令行会话。

**不知道先做什么？试着给 AI 一个小任务：**

> “帮我把这份资料整理成清晰的大纲，再给我一版适合发朋友圈的介绍。”

> “帮我做一个简单好看的个人主页，先问我需要展示哪些内容。”

## 你可能关心

**需要懂代码才能用吗？**
安装、选模型和打开工具都在图形界面完成。你可以先从写作、资料整理这些小任务开始。

**下载 EasyAI 就包含所有模型额度吗？**
下载软件和使用模型是两回事。使用平台模型需要有效的 API 订阅；也可以配置自己的 API。安装服务与订阅的价格、权益以软件内页面为准。

**Intel Mac 能用吗？**
可以下载 EasyAI Intel 版，使用支持 Intel 的工具。Codex、Claude 的 Mac 桌面版需要苹果芯片，不代表全部工具都不能用。

**更新模型后，需要重新安装工具吗？**
通常不需要。在配置中重新点击“应用配置”，就能更新可用模型列表。
